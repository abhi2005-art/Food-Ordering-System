# 🍔 Food Ordering Web Application

A full-stack web application for online food ordering, built using modern web technologies. The platform allows users to browse food items, place orders, log in, and leave feedback. This project showcases frontend UI design, backend integration, and database management for a dynamic user experience.

---

## 🚀 Features

- 🧑‍🍳 **User Authentication** – Secure login system to manage user access.
- 🔍 **Food Item Search** – Search bar to filter items dynamically.
- 🛒 **Cart System** – Add/remove food items to cart before checkout.
- 📦 **Order Management** – Orders are stored in the backend with all necessary details.
- 🗺️ **Geolocation Support** – Detects user location for better service delivery.
- 🖼️ **Responsive Design** – Fully responsive layout using Bootstrap and Carousel.
- 📝 **Feedback Form** – Collects user feedback and stores it in backend.
- 🎨 **Canvas Drawing Tool** – Users can doodle special instructions for the restaurant.
- 🧾 **Booking System** – Allows table or meal pre-booking.
  
---

## 🛠️ Tech Stack

**Frontend:**
- HTML5, CSS3
- JavaScript (ES6+)
- Bootstrap
- AngularJS
- Carousel
- Canvas API

**Backend:**
- Node.js
- PHP (for e-commerce module)
- CMD-based backend integration

**Database:**
- MySQL
- SQL (for food ordering system, used for booking & order storage)
